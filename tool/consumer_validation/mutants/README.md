# Мутанты

Каждый patch применяется к reference/data/lib/app.dart во временной копии.
Бэкенд и приёмка остаются неизменными. Это намеренно сломанные варианты,
а не допустимые решения.

| Мутант | Единственное нарушаемое свойство |
| --- | --- |
| a_no_loading | Не показывает обязательную загрузку |
| b_late_leak | Теряет значение, открытое после размонтирования |
| c_invisible_error | Не показывает обязательное сообщение ошибки |
| c_retry_no_reacquire | Retry не создаёт новую попытку |
| d_parallel_owners | Разные id занимают разные очереди, новая открывается до закрытия старой |
| d_fresh_slot_on_reopen | Open создаёт новую очередь, не ожидая предыдущий Leave |
| e_no_close_wait | Возвращает home, не дождавшись освобождения |
| general_ready_leave_leak | Обычный Leave из ready теряет ресурс; поздний результат при раннем Leave закрывается |

Одна поломка может уронить несколько сценариев: например загрузка обязательна
также при Retry и Switch. Сам факт красного процесса не считается убийством:
нужен упавший поведенческий тест; ошибка компиляции или инфраструктуры даёт
INVALID. Все мутанты должны дать KILLED.
