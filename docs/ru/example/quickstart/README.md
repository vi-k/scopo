# quickstart

> Перевод `example/quickstart/README.md` (blob `63ea8055fd10661ee55ddfb0823c633305b075b0`).
> Правится в том же коммите, что и оригинал; проверка — `sh docs/ru/check.sh`.

Один экран владеет одним локальным ресурсом через `AsyncDataScope`. Он
показывает загрузку и готовность; **Recreate scope** заменяет виджет, сохраняя
тот же `scopeKey`. Консоль печатает `closed 1` раньше `opening 2`: асинхронное
освобождение старого ресурса заканчивается до нового захвата. Каждая задержка
длится 300 мс, укладываясь в стандартные трёхсекундные пределы ожидания скоупа.

Из корня репозитория, с Flutter 3.27.0 через fvm:

```sh
cd example/quickstart
fvm flutter pub get
fvm flutter test
```

Для запуска в Chrome создайте платформенные файлы локально и запустите
приложение:

```sh
fvm flutter create --empty --platforms=web .
fvm flutter run -d chrome
```

`--empty` не даёт `flutter create` добавить свой образцовый тест: с этим
приложением он не собирается. Платформенные файлы в пример не включены. Всё
приложение — в `lib/main.dart`; плагины и внешние сервисы не нужны. Полный
`Scope` с контейнером зависимостей и состоянием разбирает
[minimal](../minimal).
